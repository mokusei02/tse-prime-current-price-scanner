# 東証プライムで現在の株価から30日以上下落しなかった銘柄

東証プライム（内国株式）の全企業を対象に、指定期間内で「現在株価以下だった最長の連続期間」が指定日数以内の企業を一覧化するローカル用Streamlitアプリです。日数はプルダウンで30日・60日・90日から選択でき、初期設定は30日です。

検索開始日の初期値は2015年1月1日です。初期設定では、3年前以前の株価履歴が確認できる「上場から3年以上」の企業だけを対象にします。

## 起動方法

1. Pythonをインストールします。
2. このフォルダーで `pip install -r requirements.txt` を実行します。
3. `起動.bat` をダブルクリックします。
4. ブラウザで `http://localhost:8501` を開きます。

全社の株価取得には数分以上かかる場合があります。Yahoo Financeの一時的な取得制限により、一部企業を取得できない場合があります。

企業一覧は日本取引所グループの「東証上場銘柄一覧」（2026年8月末）を基にしています。
